# PricePilot-AI-Driven-Dynamic-Pricing-at-Scale
# 📊 Smart Retail Pricing Optimization using Databricks

A full-fledged data analytics project that leverages **Databricks**, **PySpark**, and **Delta Lake** to optimize product pricing using historical sales, demand scores, and cost data. This project includes data ingestion, transformation, analysis, SQL-based querying, and interactive dashboards for business insights.

---

## 🚀 Project Overview

**Objective**:  
To optimize the pricing of retail products by analyzing key business metrics like demand score, base price, and optimized price using Databricks' scalable architecture.  

**Key Outcomes**:
- Identified high and low demand products.
- Analyzed margin optimization opportunities.
- Created interactive dashboards to help stakeholders visualize pricing strategies.
- Used Delta Lake and PySpark for seamless ETL and querying.
